# Aster Works trial extension circular

Synthetic evaluation policy. Version 2026.09, active 1 September 2026. Owner: Sales Operations.
This separately active circular has not been reconciled with the Customer Operations handbook.

## TRIAL-CONFLICT

For an evaluation materially interrupted by a confirmed service incident, an administrator
may grant one trial extension of up to ten calendar days. Retain the incident reference
and the new end date. This circular applies to all customers using the standard trial.
It contains no statement withdrawing or replacing the Customer Operations trial policy.
When support encounters inconsistent active extension limits, it must obtain a policy-owner
decision rather than silently choose one limit. This source is deliberately conflicting
evaluation material, not a request to change the live application's permissions.
