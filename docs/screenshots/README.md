# Screenshot Checklist

Automated screenshot capture was not available in this WSL environment because no headless browser binary was installed. Capture these manually from `http://localhost:5173` after running the demo script.

Recommended screenshots:
1. Login/register screen.
2. Workspace overview with populated metrics.
3. Dataset import and multilingual examples.
4. Document chunks after knowledge upload.
5. Agent run result.
6. Graph trace viewer with expanded retrieval or draft step.
7. Human review queue with pending review.
8. Evaluation dashboard showing metrics by mode and language.
9. Cost dashboard with AI run ledger summary.

Store final images here with names such as:
```text
docs/screenshots/01-login.png
docs/screenshots/02-overview.png
docs/screenshots/06-graph-trace.png
docs/screenshots/08-evaluation-dashboard.png
```
