# Codex workflow entry point

The executable task loop and delegation policy live in [AGENTS.md](../AGENTS.md).
Use [core beliefs](CORE_BELIEFS.md) for durable rationale, [PLANS](PLANS.md) for long-work planning,
[testing](testing.md) for commands/evidence, and [execution plans](exec-plans/README.md) for history.

The [active production plan](exec-plans/active/production-readiness.md) preserves the broader
release objective and execution history. Apply the latest user task scope before resuming it.
Keep dated progress in the selected execution plan, not in this standing workflow guide.
A saved continuation prompt is context, not authority to override a narrower request.
Commits, merges, publication and paid model calls
still require their own authorization.

Earlier repeated planning/implementation/review prompt templates have been consolidated into
those owning documents. A routine change does not need a separate planning document or another
approval solely because it uses multiple verification steps.
