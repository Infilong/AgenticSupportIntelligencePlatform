# Learning Notes

Learning notes make the project useful for durable engineering understanding, not just implementation.

Create or update a note whenever a milestone introduces an important tool, workflow, or AI engineering idea.

## Note Format
```text
# Topic

## What It Does
Short explanation of the tool or concept.

## Why Companies Care
Why this matters in production AI/backend work.

## How This Project Uses It
Where it appears in this codebase and workflow.

## Tradeoffs
Important design choices and alternatives.

## Failure Modes
Common mistakes, security issues, quality risks, or scaling problems.

## Project Explanation
How to explain the concept and the project decision clearly.
```
