## Summary

No prior baseline file was found during this run, so this report is an absolute benchmark, not a regression comparison.

The production-built landing page is fast and small enough for the current portfolio app. The main concern is the authenticated dev app shell: after login it triggers 30 API fetches and 63 total browser requests in the current Vite dev-server mode. That is not a production bundle regression, but it is a product-performance signal: the app shell is doing broad eager loading across many panels.

## Recommendations

1. Capture this report as the first baseline before large UI or data-fetching changes.
2. Add a production frontend serving mode to Docker or a separate `frontend-preview` target. Current Docker frontend runs Vite dev mode, which is useful for development but noisy for performance benchmarking.
3. Reduce authenticated app-shell eager loading. The Account page should not need to load guardrails, model configs, prompts, tools, evaluations, multiple folder counts, and system health before the user opens those sections.
4. Watch the JS bundle. At 471 KB raw, it passes the current 500 KB budget but leaves little room for new frontend dependencies.
